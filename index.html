Key Operational Rules

🛡️
Anti-Illusion Rule
Recognition ≠ Recall. If a fact is only recognized after looking at text → classify as Forgotten.
Re-learn → Immediate Active Recall (book closed)
📖
3-Read Throttling
If comprehension fails after 3 readings of the same paragraph, stop re-reading.
Mark Blocked → Consult external source
⏱️
8-Minute Boundary
Cap time per page at 8 minutes to prevent diminishing returns.
Mark ⋆ → Move on → Return later
🎯
Golden Question of Mastery
"Could I reproduce this in an exam without any cues?" — If not a definitive Yes, it's a blind spot.
Treat as Blind Spot → Re-study immediately

Session Completion Criteria

1 All paragraphs passed Comprehension check
2 Self-Explanation in original vernacular
3 Active Recall threshold ≥ 80% (book closed)
4 All Forgotten items re-studied & recalled immediately

Study Flowchart Stages

🟡 First-Time Study
Read Para → Understand? → Own Words? → Repeat All Paras → Close Book → Total Page Recall → Open & Check
IF Recalled → Remembered  |  ELSE → Forgot → Recall Now
Exit: All paras comprehended + self-explained + recalled ≥ 80%
🔵 Revision 1
Start Page (Book Closed) → Complete Page Recall → Open & Check → Correction Loop
Errors found? → Re-read → Close book → Recall again
Exit: Full page recalled with zero errors
🟢 Revision 2+
Start Page (Book Closed) → Rapid Recall → Open & Verify → 20–30s Quick Scan
If NO recall → drop back to Revision 1 flow
Exit: Rapid recall in under 30 seconds

Cognitive Strategies

🔀 Interleaving
Mix related topics instead of studying one for hours. Forces the brain to distinguish similar concepts.
Alternate subjects within a session; use Ghost Subject slots for variety
🖼️ Dual Coding
Combine verbal descriptions with visual representations. Sketch diagrams alongside text.
Always sketch diagrams/flowcharts alongside text notes
⏸️ Zeigarnik Effect
Pause during difficult problems — the brain maintains "cognitive tension" and processes in the background.
Pause 5–10 min during hard sections, then return
🤔 Metacognitive Monitoring
After every recall, ask: "Why is this fact true?" Moves rote memorization → relational encoding.
Write 1 "why" sentence per key fact after each recall pass
🌙 Sleep Consolidation
Review hardest Forgotten items 30 min before sleep. Hippocampus replays during Slow Wave Sleep.
Mark hardest F items during the day → review at 11:00 PM
📍 Environment Variation
Change study locations to prevent context-dependent forgetting.
Aim for ≥ 2 different environments per module
